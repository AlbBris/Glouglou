# Glouglou — Pack GitHub Pages

Ce dossier est prêt à être envoyé tel quel dans un dépôt GitHub.

## Fichiers principaux
- `index.html` : l'application
- `manifest.webmanifest` : installation PWA
- `sw.js` : fonctionnement hors-ligne / installation
- `apple-touch-icon.png` : icône iPhone / iPad
- `icon-192.png`, `icon-512.png` : icônes Android / PWA
- `icon-maskable-512.png` : icône Android adaptative
- `favicon.ico`, `favicon-32.png` : icône du navigateur
- `logo-glouglou.png` : logo source haute résolution

## Mise en ligne sur GitHub Pages
1. Créer ou ouvrir le dépôt GitHub destiné à Glouglou.
2. Mettre **tous les fichiers de ce dossier à la racine du dépôt**.
3. Aller dans `Settings` > `Pages`.
4. Dans `Build and deployment`, choisir `Deploy from a branch`.
5. Sélectionner `main` et `/ (root)`, puis enregistrer.
6. Ouvrir l'adresse GitHub Pages une fois le déploiement terminé.

## Ajouter sur l'écran d'accueil d'un iPhone
1. Ouvrir le site Glouglou dans Safari.
2. Appuyer sur le bouton Partager.
3. Choisir `Sur l'écran d'accueil`.
4. L'icône Glouglou apparaîtra comme une application.

Les consommations sont enregistrées dans le stockage local du navigateur sur l'appareil utilisé.
